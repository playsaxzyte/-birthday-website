# Birthday Website

A small interactive birthday website I made as a reusable template.

The idea is pretty simple: instead of sending someone a birthday story or a bunch of photos, you can make them a little website with their own photos, videos, songs and memories.

I originally made this for a friend, then cleaned it up so other people can use the same structure for their own projects.

---

## What it has

- Full-screen birthday intro
- Background video
- Small music player
- Photo archive
- Video section with hover playback
- Family / Friends / Us sections
- Rotating thoughts section
- Lore / easter egg section
- Responsive layout for desktop and mobile
- Scroll-based animations
- GitHub Pages support

You can change pretty much all of the personal content without touching the main JavaScript.
